# Changelog

## 0.2.0

- Added a desktop interface alongside the CLI, including multiple plugin profiles, engine discovery, per-plugin settings, and live task logs.
- Added source submission inspection for ZIPs and plugin folders, result filtering, and JSON / Markdown reports.
- Added optional compilation validation, source and binary archives, file inventories, and SHA256 verification.
- Added low-memory compilation settings and a force-stop control for the tool's build process tree.
- Applied a consistent dark palette across both pages and improved text contrast and auxiliary text size.

## 0.1.0

- Initial command-line engine discovery, profile setup, and plugin packaging workflow.
